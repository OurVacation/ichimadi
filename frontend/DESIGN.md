# 이치마디 디자인 규칙

> 2026-11-28 · 태영 결정. 시안 비교(Instagram · 한옥 · 병합 → 한옥 3안 → 밤·낮) 끝에 **한옥, 낮 기본 + 밤 토글**로 정했다.
> 같은 날 2차 피드백: 기본을 낮으로, 토글은 아이콘만(해 → 달), 지붕은 화면 맨 위 처마 띠, 카드 상자 통일, 상대방 화면도 같은 톤, 도장첩은 옛 책.
> 화면을 만들거나 고칠 때 이 파일을 따른다. 바꾸려면 이 파일을 먼저 고친다.

## 1. 컨셉

- **한옥 처마 아래의 창.** 한마디가 통할 때마다 창호지 창에 불이 하나씩 켜진다. 낮에는 한옥 카페, 밤에는 별이 뜬 한옥 골목.
- 누구를 위해: 서울을 다시 찾는 20~30대 일본인 여행객(방한 일본인의 여성 67~68%, 20~30대 여성 34%). 내일의 실제 사용자는 DigiMan 심사위원.
- 피할 것: 학습 앱처럼 보이는 것. **초록 계열 금지**(Duolingo·LINE·Papago 인상). 전통 박물관처럼 무거운 것.

## 2. 테마

| | 낮 (기본) | 밤 (토글) |
|---|---|---|
| 분위기 | 한옥 카페: 아이보리 한지, 밝은 오크, 해 | 별·초승달이 뜬 밤하늘, 불 켜진 창 |
| 언제 | 처음 열면 항상 낮 (기기 설정과 무관) | 오른쪽 위 토글의 달 아이콘 |

- 두 모드는 **문구·레이어·크기·배치가 같고 색만 다르다.** 한쪽에만 있는 요소를 만들지 않는다.
- 고른 모드는 기기에 기억한다(`ichimadi:theme`). 저장은 `src/core/theme.ts`에서만 한다.
- `<html data-theme="night|day">`. 색은 모두 `index.css` 맨 위 토큰으로 쓰고, 컴포넌트에 색을 직접 쓰지 않는다.
- 토글은 오른쪽 위, **아이콘만**: 해(낮) → 달(밤) 순서. 고른 쪽이 채워진 원으로 보인다.
- 상대방 화면(「알아들었어요」)도 **같은 톤**(하늘 바탕, 창호지 상자, 주 버튼)이다. 상대가 누르는 화면이라 토글만 두지 않는다. 버튼은 크게(104px).

- 창호지 상자(카드의 세 상자, 상대방 화면 본문, 도장첩 한 장)는 두 모드 모두 **창호지색 바탕 + 먹색 글자 + `--frame` 3px 테두리 + 모서리 16px + 은은한 불빛**으로 똑같이 쓴다.

## 4. 글꼴

- 제목·브랜드·「通じた！」: 명조 `Shippori Mincho` (대체: Hiragino Mincho ProN, serif)
- 본문·버튼: `Zen Kaku Gothic New` (대체: Hiragino Sans, system-ui)
- 한국어 한마디: `Nanum Myeongjo` (대체: AppleMyungjo, Apple SD Gothic Neo)
- Google Fonts는 `display=swap`. 느린 와이파이에서도 대체 글꼴로 바로 보인다.

## 6. 화면별

- **로그인**: 처마 → 브랜드 → 태그라인 → 로그인 상자.
- **설정**: 이름 → 후보 → 동물 4종(틀 없는 동물 도장) → 미리보기(낙관).
- **한마디판**: 처마 → 「イチマディ」 → 「灯りがともったのは n / 6」 → 창 6칸 → 아래 탭(ひとこと / スタンプ帳).
- **카드**: 「← ひとことへ」 → 창호지 상자 셋(한마디+가타카나+뜻+듣기 / 쓰는 때 / 상대 대답) → 주 버튼.
- **상대방**: 「この画面を相手に見せてください」 → 창호지 상자(안내 + 「한마디」) → 큰 「알아들었어요」 → 「다시 한 번」.
- **도장 획득**: 처마(청사초롱) → 뒤에서 빛 → 큰 낙관 → 「通じた！」 → 한국어 한마디 / 뜻 · 시각 → 「n つ目の灯りがともりました」 → 버튼 2개.
- **도장첩**: 먼저 **덮인 옛 책(표지)**. 누르면 열리고(0.45초) **한 장에 한마디 하나**: 번호(一…) → 낙관(아직이면 점선 「まだ」) → 한국어 한마디 → 뜻 → 시각. 「← 前へ / 次へ →」 또는 옆으로 밀어 넘긴다. 마지막 장에서 다 모았으면 「コンプリート！」, 「表紙に戻る」.

## 7. 움직임

- 복주머니 흔들기 0.45초 + 뚜껑 0.35초, 도장 「쾅」 0.45초, 책 표지 열기 0.45초, 장 넘기기 0.3초. 그 밖의 장식 애니메이션은 넣지 않는다.
- `prefers-reduced-motion`이면 모두 끈다.

## 8. 지키는 것

- 화면 문구는 일본어만(한마디·상대방 화면 제외). 문구는 `src/i18n.ts`에만.
- 버튼·링크 터치 영역 44px 이상. 본문 대비 4.5:1 이상(밤의 `--muted`도 포함).
- 「1분 안에 도장 하나」를 느리게 하는 장식(로딩을 기다리게 하는 그림, 큰 이미지 파일)은 넣지 않는다. 그림은 모두 SVG·CSS.
